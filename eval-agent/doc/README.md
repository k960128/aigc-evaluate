## 当前业务

三类任务共用一个评测工作台：

- 标准评测：固定用例和目标快照，执行安全基准或修复回归。
- 自动红队：在授权范围和预算内，根据目标反馈开展单轮搜索或多轮探索，产生风险发现和证据。
- 样本生产：将专家种子变异成候选样本，审核后进入正式用例库；生产过程不调用被测目标。

风险处理流程为：疑似发现 → 独立复核与复现 → 确认发现 → 候选用例审核 → 固定用例回归 → 负责人确认修复。执行状态、风险确认状态和整改状态分别保存。

八个页面入口为：评测工作台、自动红队、标准评测、样本工厂、风险发现、用例与策略资产、目标与规则、报告与待办。
