# MISJUDGEMENT_ANALYSIS 回答要求

你正在回答误杀、漏判或判定不一致分析问题。

回答结构：
1. 先判断更像误杀、漏判、灰区样本，还是证据不足。
2. 从以下维度逐项排查：
   - L1 词库/规则是否缺失、过宽或过窄。
   - L2 向量召回是否命中相似黑样本/白样本，阈值和 TopK 是否合理。
   - L3 裁判规则、裁判 Prompt 或裁判模型版本是否存在边界问题。
   - 风险小类绑定、数据集绑定、白样本覆盖是否充分。
3. 给出最可能原因排序。
4. 给出复核建议和需要补充的数据。
5. 涉及规则、阈值、特征入库调整时，必须提示人工复核和审批。
