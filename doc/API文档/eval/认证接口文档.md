# AuthController API 接口文档

## 通用说明

- Controller 基础路径：`/auth`
- 所有接口均使用统一响应结构 `Result<T>`。
- 成功状态码：`code = "0"`。
- 登录接口请求体使用 `@Validated` 校验，`username`、`password` 均声明 `@NotBlank`。
- 登录成功后由 Sa-Token 写入登录态并返回 `SaTokenInfo`；登出接口在当前请求已登录时执行 `StpUtil.logout()`，未登录时也返回成功。

### 统一响应结构

```json
{
  "code": "0",
  "message": null,
  "data": {},
  "requestId": null
}
```

| 字段名 | 数据类型 | 说明 |
|---|---|---|
| code | String | 响应状态码，`"0"` 表示成功 |
| message | String | 响应消息，成功时通常为空 |
| data | Object / null | 业务响应数据 |
| requestId | String | 请求追踪 ID，当前成功响应构造器未主动设置 |

## 1. 用户登录

### 接口基本信息

| 项目 | 内容 |
|---|---|
| 接口名称 | 用户登录 |
| 请求路径 | `/auth/login` |
| 请求方式 | POST |
| 接口描述 | 根据用户名和密码校验用户身份；校验通过后写入 Sa-Token 登录态，并返回当前登录 token 信息。 |

### 请求参数说明

请求体：`LoginRequest`

| 参数名 | 必填 | 参数类型 | 请求位置 | 说明 |
|---|---|---|---|---|
| username | 是 | String | Body | 用户名，字段声明了 `@NotBlank` |
| password | 是 | String | Body | 密码，字段声明了 `@NotBlank` |

### 响应参数说明

```json
{
  "code": "0",
  "message": null,
  "data": {
    "tokenName": "satoken",
    "tokenValue": "8f7d0c1e-xxxx-xxxx-xxxx-2d3c4b5e6f70",
    "isLogin": true,
    "loginId": "admin",
    "loginType": "login",
    "tokenTimeout": 2592000,
    "sessionTimeout": 2592000,
    "tokenSessionTimeout": 2592000,
    "tokenActiveTimeout": -1,
    "loginDevice": "default-device",
    "tag": null
  },
  "requestId": null
}
```

| 字段名 | 数据类型 | 说明 |
|---|---|---|
| data.tokenName | String | token 名称，前端通常按该名称写入请求头或 Cookie |
| data.tokenValue | String | token 值，后续请求携带该值完成鉴权 |
| data.isLogin | Boolean | 当前会话是否已登录 |
| data.loginId | Object / String | 当前登录用户 ID |
| data.loginType | String | 登录类型 |
| data.tokenTimeout | Long | token 剩余有效期，单位秒；具体语义以 Sa-Token 配置为准 |
| data.sessionTimeout | Long | Session 剩余有效期，单位秒 |
| data.tokenSessionTimeout | Long | Token-Session 剩余有效期，单位秒 |
| data.tokenActiveTimeout | Long | token 最低活跃频率配置，单位秒；`-1` 通常表示不限制 |
| data.loginDevice | String | 登录设备标识 |
| data.tag | String | token 标签 |

## 2. 用户登出

### 接口基本信息

| 项目 | 内容 |
|---|---|
| 接口名称 | 用户登出 |
| 请求路径 | `/auth/logout` |
| 请求方式 | POST |
| 接口描述 | 当前请求存在登录态时注销登录；当前请求未登录时不执行注销动作，但仍返回成功响应。 |

### 请求参数说明

无请求参数。

### 响应参数说明

```json
{
  "code": "0",
  "message": null,
  "data": null,
  "requestId": null
}
```

| 字段名 | 数据类型 | 说明 |
|---|---|---|
| data | null | 登出成功时无业务返回数据 |

## 前端对接注意事项

1. `/auth/login` 成功后请保存 `data.tokenName` 和 `data.tokenValue`，后续请求按项目鉴权配置携带 token。
2. 登录失败时 Service 会抛出业务异常，错误码和错误消息以全局异常处理结果为准。
3. `/auth/logout` 对未登录请求也返回成功，前端可在调用后直接清理本地登录态。
