# RiskScenarioController API 接口文档

## 通用说明

- Controller 基础路径：`/risk/scenarios`
- 所有接口均使用统一响应结构 `Result<T>`。
- 成功状态码：`code = "0"`。
- 时间字段来自 `LocalDateTime`，接口序列化通常为 ISO-8601 字符串，例如 `2026-06-08T15:30:00`；如项目全局 Jackson 配置或字段注解生效，也可能返回 `2026-06-08 15:30:00`。
- 当前 Controller 未使用 `@Validated`，请求 DTO 字段也未声明 `@NotNull`、`@NotBlank` 等 Bean Validation 注解；Body 内字段按源码校验结果标注为非必填，`@RequestParam` 参数按 Spring 默认规则标注为必填。
- 分页查询当 `current` 或 `size` 为空时，后端分别使用默认值 `current = 1`、`size = 10`；结果按 `createTime` 降序返回。
- 更新风险场景时，如果目标记录不存在，接口返回成功响应且 `data = null`。

### 统一响应结构

```json
{
  "code": "0",
  "message": null,
  "data": {},
  "requestId": null
}
```

| 字段名 | 数据类型 | 说明 |
|---|---|---|
| code | String | 响应状态码，`"0"` 表示成功 |
| message | String | 响应消息，成功时通常为空 |
| data | Object / Array / null | 业务响应数据 |
| requestId | String | 请求追踪 ID，当前成功响应构造器未主动设置 |

### 枚举和约定

| 字段 | 可选值 | 说明 |
|---|---|---|
| severityLevel | `1`、`2`、`3`、`4` | 严重等级：1-低，2-中，3-高，4-致命 |
| status | `0`、`1` | 业务状态：0-禁用，1-启用 |

### 分页响应结构

分页接口返回 MyBatis-Plus `Page<T>`。

```json
{
  "records": [],
  "total": 0,
  "size": 10,
  "current": 1,
  "pages": 0
}
```

| 字段名 | 数据类型 | 说明 |
|---|---|---|
| records | Array | 当前页记录列表 |
| total | Long | 总记录数 |
| size | Long | 每页数量 |
| current | Long | 当前页码 |
| pages | Long | 总页数 |

## 1. 创建风险场景

### 接口基本信息

| 项目 | 内容 |
|---|---|
| 接口名称 | 创建风险场景 |
| 请求路径 | `/risk/scenarios/create` |
| 请求方式 | POST |
| 接口描述 | 创建一条风险场景记录，包含所属风险大类、场景编码、场景名称、裁判规则、严重等级和状态等信息。 |

### 请求参数说明

请求体：`CreateRiskScenarioRequest`

| 参数名 | 必填 | 参数类型 | 请求位置 | 说明 |
|---|---|---|---|---|
| majorCategoryId | 否 | Long | Body | 直属风险大类 ID |
| scenarioCode | 否 | String | Body | 场景全局唯一编码 |
| scenarioName | 否 | String | Body | 场景名称 |
| judgeRule | 否 | String | Body | 裁判系统指令或判定规则 |
| severityLevel | 否 | Integer | Body | 严重等级：1-低，2-中，3-高，4-致命 |
| status | 否 | Integer | Body | 业务状态：0-禁用，1-启用 |
| creator | 否 | String | Body | 创建人 |

### 响应参数说明

```json
{
  "code": "0",

    "createTime": "2026-06-08T15:10:00",
    "updateTime": "2026-06-08T15:10:00"

```

| 字段名 | 数据类型 | 说明 |
|---|---|---|
| data.id | Long | 风险场景 ID |
| data.majorCategoryId | Long | 直属风险大类 ID |
| data.scenarioCode | String | 场景全局唯一编码 |

## 前端对接注意事项

1. `severityLevel` 请统一按 `1` 低、`2` 中、`3` 高、`4` 致命渲染。
2. `status` 请统一按 `0` 禁用、`1` 启用渲染。
3. 更新风险场景时，如果 `id` 对应数据不存在，接口返回成功响应且 `data = null`，前端需要兼容空数据。
4. 删除接口返回 `Result<Void>`，成功时 `data` 为空。
5. `/risk/scenarios/page` 当前未对 `current`、`size` 小于等于 0 的情况做修正，仅在字段为空时使用默认值。
