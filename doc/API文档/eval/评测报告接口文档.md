# 评测报告接口文档

## 通用说明

- 报告接口基于评测执行批次生成，入口参数为 `taskDetailId`。
- 报告口径为“全量统计 + 问题样本明细”：所有样本参与统计，明细默认只返回违规、人工核验和失败样本。
- 安全样本明细不在报告中展开，可继续通过 `/eval-task/result/page` 分页查询。
- 运行中的批次也可以生成报告快照，响应中的 `meta.finalized` 用于区分是否终态报告。

## 获取评测报告

| 项目 | 内容 |
|---|---|
| 接口名称 | 获取评测批次报告 |
| 请求路径 | `/eval-task/report` |
| 请求方式 | GET |
| 响应结构 | `Result<EvalTaskReportVO>` |

### 请求参数

| 参数名 | 必填 | 类型 | 位置 | 说明 |
|---|---|---|---|---|
| taskDetailId | 是 | Long | Query | 评测执行批次 ID |
| topN | 否 | Integer | Query | 问题样本返回数量，默认 `10`，最大 `50` |

### 响应字段

| 字段 | 类型 | 说明 |
|---|---|---|
| meta | Object | 任务、批次、模型、数据集、状态和报告生成时间 |
| execution | Object | 执行统计，包括各结果状态计数、进度、失败率、停止率 |
| safety | Object | 安全统计，包括安全数、违规数、人工核验数和分离口径比例 |
| riskBreakdown | Array | 按风险大类和风险小类聚合的全量样本结果 |
| pipelineBreakdown | Array | 按 `MODEL_CALL/L1/L2/L3` 和节点状态聚合的流水线执行统计 |
| unsafeSamples | Array | 违规样本摘要，最多 `topN` 条 |
| manualReviewSamples | Array | 人工核验样本摘要，最多 `topN` 条 |
| failedSamples | Array | 执行失败样本摘要，最多 `topN` 条 |

### 统计口径

| 指标 | 口径 |
|---|---|
| executionSuccessRate | `(AUTO_SCORED + MANUAL_REVIEWED) / totalCount` |
| failedRate | `FAILED / totalCount` |
| stoppedRate | `STOPPED / totalCount` |
| safeRate | `safeCount / (safeCount + unsafeCount)` |
| riskRate | `unsafeCount / (safeCount + unsafeCount)` |
| manualReviewRate | `manualReviewCount / (safeCount + unsafeCount + manualReviewCount)` |
