# SourceController API 接口文档

## 通用说明

- Controller 基础路径：`/source`
- 所有接口均使用统一响应结构 `Result<T>`。
- 成功状态码：`code = "0"`。
- 时间字段来自 `LocalDateTime`，接口序列化通常为 ISO-8601 字符串，例如 `2026-06-08T15:30:00`；如项目全局 Jackson 配置或字段注解生效，也可能返回 `2026-06-08 15:30:00`。
- 当前 Controller 未使用 `@Validated`，请求 DTO 字段也未声明 `@NotNull`、`@NotBlank` 等 Bean Validation 注解；Body 内字段按源码校验结果标注为非必填，`@RequestParam` 参数按 Spring 默认规则标注为必填。
- 更新模型厂商或模型配置时，如果目标记录不存在，接口返回成功响应且 `data = null`。

### 统一响应结构

```json
{
  "code": "0",
  "message": null,
  "data": {},
  "requestId": null
}
```

| 字段名 | 数据类型 | 说明 |
|---|---|---|
| code | String | 响应状态码，`"0"` 表示成功 |
| message | String | 响应消息，成功时通常为空 |
| data | Object / Array / null | 业务响应数据 |
| requestId | String | 请求追踪 ID，当前成功响应构造器未主动设置 |

### 枚举和约定

| 字段 | 可选值 | 说明 |
|---|---|---|
| manufacturerCode | `OPENAI`、`DEEPSEEK`、`QWEN`、`TELE`、`SPARK`、`GLM`、`KIMI`、`GPT`、`MOCK` | 模型厂商编码；连通性测试时会转为 `ModelManufacturerEnum`，大小写由后端转为大写后匹配 |
| enable | `true`、`false` | 模型厂商是否启用 |
| status | `true`、`false` | 模型配置是否启用；创建模型配置时 Controller 当前固定设置为 `true` |
| stream | `true`、`false` | 是否使用流式响应 |

## 1. 创建模型厂商

### 接口基本信息

| 项目 | 内容 |
|---|---|
| 接口名称 | 创建模型厂商 |
| 请求路径 | `/source/manufacturer/create` |
| 请求方式 | POST |
| 接口描述 | 创建一条模型厂商配置，包含厂商名称、厂商编码、默认 Base URL、描述、图标和启用状态。 |

### 请求参数说明

请求体：`CreateModelManufacturerRequest`

| 参数名 | 必填 | 参数类型 | 请求位置 | 说明 |
|---|---|---|---|---|
| manufacturerName | 否 | String | Body | 厂商名称，例如：`DeepSeek` |
| manufacturerCode | 否 | String | Body | 厂商编码，例如：`DEEPSEEK` |
| defaultBaseUrl | 否 | String | Body | 默认模型服务 Base URL |
| describe | 否 | String | Body | 厂商描述 |
| icon | 否 | String | Body | 厂商图标地址或标识 |
| enable | 否 | Boolean | Body | 是否启用 |

### 响应参数说明

```json
{
  "code": "0",
  "message": null,
  "data": {
    "id": 1,
    "manufacturerName": "DeepSeek",
    "manufacturerCode": "DEEPSEEK",

    "icon": "deepseek",
    "enable": true,
    "createTime": "2026-06-08T15:10:00",
    "updateTime": "2026-06-08T15:10:00"
  },
  "requestId": null
}
```

| 字段名 | 数据类型 | 说明 |
|---|---|---|
| data.id | Integer | 模型厂商 ID |
| data.manufacturerName | String | 厂商名称 |
| data.manufacturerCode | String | 厂商编码 |
| data.defaultBaseUrl | String | 默认模型服务 Base URL |

## 前端对接注意事项

1. 创建模型配置时，后端当前固定保存 `status = true`，前端不要依赖请求体中的 `status` 控制初始状态。
2. 更新模型厂商或模型配置时，如果 `id` 对应数据不存在，接口返回成功响应且 `data = null`，前端需要兼容空数据。
3. 删除接口返回 `Result<Void>`，成功时 `data` 为空。
4. `/source/model/testConnectivity` 的 `manufacturerCode` 会按大写匹配 `ModelManufacturerEnum`，不支持的编码会触发业务异常。
5. 模型配置响应中包含 `apiKey`，前端展示时应避免明文泄露或在界面上做脱敏处理。
