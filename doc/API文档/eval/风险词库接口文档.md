# KnowledgeVocabularyKeywordController API 接口文档

## 通用说明

- Controller 基础路径：`/knowledge/vocabularies`
- 所有接口均使用统一响应结构 `Result<T>`。
- 成功状态码：`code = "0"`。
- 时间字段来自 `LocalDateTime`，接口序列化通常为 ISO-8601 字符串，例如 `2026-06-08T15:30:00`；如项目全局 Jackson 配置或字段注解生效，也可能返回 `2026-06-08 15:30:00`。
- 当前 Controller 未使用 `@Validated`，请求 DTO 字段也未声明 `@NotNull`、`@NotBlank` 等 Bean Validation 注解；Body 内字段按源码校验结果标注为非必填，`@RequestParam` 参数按 Spring 默认规则标注为必填。
- 创建、更新、删除风险词库特征词时，Controller 会标记相关风险明细分片为脏数据，供后续 AC 快照发布流程使用。
- 分页查询当 `current` 或 `size` 为空时，后端分别使用默认值 `current = 1`、`size = 10`；结果按 `createTime` 降序返回。

### 路径变更说明

| 变更项 | 旧路径 | 新路径 | 调用方影响 |
|---|---|---|---|
| Controller 基础路径 | `/risk/vocabularies` | `/knowledge/vocabularies` | 词库接口已从 risk 域迁移到 knowledge 域；HTTP 方法、请求体和响应结构保持不变，前端和网关只需更新路径前缀。 |

### 统一响应结构

```json
{
  "code": "0",
  "message": null,
  "data": {},
  "requestId": null
}
```

| 字段名 | 数据类型 | 说明 |
|---|---|---|
| code | String | 响应状态码，`"0"` 表示成功 |
| message | String | 响应消息，成功时通常为空 |
| data | Object / Array / Boolean / String / null | 业务响应数据 |
| requestId | String | 请求追踪 ID，当前成功响应构造器未主动设置 |

### 枚举和约定

| 字段 | 可选值 | 说明 |
|---|---|---|
| riskLevel | `1`、`2`、`3`、`4` | 风险等级：1-低，2-中，3-高，4-致命；源码注释中也表达了高危/疑似等级语义，最终展示文案以产品约定为准 |
| matchType | `1`、`2` | 匹配模式：1-精确匹配，2-模糊包含匹配 |
| syncStatus | `false`、`true` | AC 快照同步状态：`false`-待同步，`true`-已同步 |

### 分页响应结构

分页接口返回 MyBatis-Plus `Page<T>`。

```json
{
  "records": [],
  "total": 0,
  "size": 10,
  "current": 1,
  "pages": 0
}
```

| 字段名 | 数据类型 | 说明 |
|---|---|---|
| records | Array | 当前页记录列表 |
| total | Long | 总记录数 |
| size | Long | 每页数量 |
| current | Long | 当前页码 |
| pages | Long | 总页数 |

## 1. 创建风险词库特征词

### 接口基本信息

| 项目 | 内容 |
|---|---|
| 接口名称 | 创建风险词库特征词 |
| 请求路径 | `/knowledge/vocabularies/keyword/create` |
| 请求方式 | POST |
| 接口描述 | 创建一条风险词库特征词。当前 Controller 会将 `syncStatus` 固定设置为 `false`，并标记该风险明细分片为脏数据。 |

### 请求参数说明

请求体：`CreateRiskVocabularyKeywordRequest`

| 参数名 | 必填 | 参数类型 | 请求位置 | 说明 |
|---|---|---|---|---|
| groupId | 否 | Long | Body | 所属分组 ID；当前响应 VO 不返回该字段 |
| riskDetailsId | 否 | Long | Body | 所属风险明细 ID |
| keyword | 否 | String | Body | 字面量特征词 |
| riskLevel | 否 | Integer | Body | 风险等级：1-低，2-中，3-高，4-致命 |

| syncStatus | 否 | Boolean | Body | 请求 DTO 存在该字段，但当前创建逻辑固定保存为 `false` |
| creator | 否 | String | Body | 创建人 |

| 字段名 | 数据类型 | 说明 |

## 前端对接注意事项

1. 创建和更新特征词时，后端当前都会将 `syncStatus` 重置为 `false`，表示需要重新发布 AC 快照后才进入线上匹配快照。
2. 创建、更新、删除特征词会标记相关风险明细分片为脏数据；发布快照接口会基于后端 Service 实现处理待同步数据。
3. 删除接口返回 `Result<Void>`，成功时 `data` 为空。
4. 更新特征词时，如果 `id` 对应数据不存在，接口返回成功响应且 `data = null`，前端需要兼容空数据。
5. `/knowledge/vocabularies/keyword/page` 的 `syncStatus` 请求字段类型为 `Integer`，而响应 VO 中为 `Boolean`；前端筛选入参应以后端实际序列化兼容结果为准。
6. 当前 `KnowledgeVocabularyKeywordController` 源码仅暴露 `/keyword/version/publish`，未暴露 `/keyword/version/publishV2`，因此本文档不记录 V2 发布接口。
