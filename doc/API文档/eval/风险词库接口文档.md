# KnowledgeRiskKeywordController API 接口文档

## 通用说明

- Controller 基础路径：`/knowledge/risk/keyword`。
- 所有接口均使用统一响应结构 `Result<T>`，成功状态码为 `code = "0"`。
- 创建、更新、分页查询接口使用 JSON 请求体，请设置 `Content-Type: application/json`。请求体必传；分页查询无筛选条件时传 `{}`。
- 当前 Controller 未使用 `@Validated` 或 `@Valid`，请求 DTO 未声明 `@NotNull`、`@NotBlank` 等 Bean Validation 注解；下文 Body 字段的“必填”按源码校验情况标注。业务上创建时应提供 `riskDetailsId`、`keyword`、`matchType`，更新时必须提供 `id`。
- 删除采用逻辑删除，详情、列表和分页查询自动排除已删除记录。
- 时间字段格式为 `yyyy-MM-dd HH:mm:ss`，例如 `2026-11-27 15:30:00`。
- 列表和分页结果均按 `riskDetailsId` 升序、`updateTime` 降序、`id` 降序排列。
- 分页参数 `current`、`size` 为空或小于等于 `0` 时，分别使用默认值 `1`、`10`。

### 统一响应结构

以下示例展示统一响应的主要字段，省略默认序列化可能包含的 `success` 衍生字段。`success = true` 仅表示 `code = "0"`，布尔操作是否成功仍应判断 `data`。

```json
{
  "code": "0",
  "message": null,
  "data": {},
  "requestId": null
}
```

| 字段名 | 数据类型 | 说明 |
|---|---|---|
| code | String | 响应状态码，`"0"` 表示请求正常处理 |
| message | String | 响应消息，成功时通常为空 |
| data | Object / Array / Boolean / null | 业务响应数据，具体类型见各接口说明 |
| requestId | String | 请求追踪 ID，当前成功响应构造器未主动设置 |
| success | Boolean | 默认序列化可能包含的衍生字段，表示 `code` 是否为 `"0"`，不代表布尔操作结果 `data` 为 `true` |

### 枚举和约定

| 字段 | 可选值 | 说明 |
|---|---|---|
| matchType | `0`、`1` | 匹配类型：0-全量匹配，1-包含匹配；创建接口不补充默认值 |
| deleted | `false`、`true` | 逻辑删除标记：`false`-未删除，`true`-已删除；创建时由后端设置为 `false`，查询返回的正常记录为 `false` |

### 风险词响应结构

详情、列表和分页查询中的风险词对象均为 `KnowledgeRiskKeywordVO`。

| 字段名 | 数据类型 | 说明 |
|---|---|---|
| id | Long | 风险词 ID |
| riskDetailsId | Long | 所属风险明细 ID，对应 `risk_details.id` |
| keyword | String | 字面量特征词 |
| matchType | Integer | 匹配类型：0-全量匹配，1-包含匹配 |
| creator | String | 创建人 |
| updater | String | 更新人 |
| createTime | String | 创建时间，格式 `yyyy-MM-dd HH:mm:ss` |
| updateTime | String | 更新时间，格式 `yyyy-MM-dd HH:mm:ss` |
| deleted | Boolean | 逻辑删除标记，正常查询记录为 `false` |

### 分页响应结构

分页接口返回 MyBatis-Plus `Page<KnowledgeRiskKeywordVO>`，主要分页字段如下。

```json
{
  "records": [],
  "total": 0,
  "size": 10,
  "current": 1,
  "pages": 0
}
```

| 字段名 | 数据类型 | 说明 |
|---|---|---|
| records | Array | 当前页风险词列表，元素结构见“风险词响应结构” |
| total | Long | 总记录数 |
| size | Long | 每页数量 |
| current | Long | 当前页码 |
| pages | Long | 总页数 |

## 1. 创建风险词库特征词

### 接口基本信息

| 项目 | 内容 |
|---|---|
| 接口名称 | 创建风险词库特征词 |
| 请求路径 | `/knowledge/risk/keyword/create` |
| 请求方式 | POST |
| 接口描述 | 创建一条风险词库特征词，后端将逻辑删除标记 `deleted` 设置为 `false`。 |

### 请求参数说明

请求体：`CreateKnowledgeRiskKeywordRequest`。

| 参数名 | 必填 | 参数类型 | 请求位置 | 说明 |
|---|---|---|---|---|
| riskDetailsId | 否 | Long | Body | 所属风险明细 ID，业务上应提供 |
| keyword | 否 | String | Body | 字面量特征词，业务上应提供非空文本 |
| matchType | 否 | Integer | Body | 匹配类型，业务上应提供 `0` 或 `1`；后端不补充默认值 |
| creator | 否 | String | Body | 创建人 |

### 请求示例

```json
{
  "riskDetailsId": 2001,
  "keyword": "绕过内容审核",
  "matchType": 1,
  "creator": "admin"
}
```

### 响应参数说明

返回 `Result<Boolean>`。

```json
{
  "code": "0",
  "message": null,
  "data": true,
  "requestId": null
}
```

| 字段名 | 数据类型 | 说明 |
|---|---|---|
| data | Boolean | 是否创建成功；返回操作结果，不返回风险词对象或新记录 ID |

## 6. 分页查询风险词库特征词

### 接口基本信息

| 项目 | 内容 |
|---|---|
| 接口名称 | 分页查询风险词库特征词 |
| 请求路径 | `/knowledge/risk/keyword/page` |
| 请求方式 | POST |
| 接口描述 | 分页查询未删除的风险词，支持按风险明细 ID、关键词和匹配类型组合筛选。结果按风险明细 ID 升序、更新时间降序、ID 降序排列。 |

### 请求参数说明

请求体：`KnowledgeRiskKeywordPageRequest`。请求体必传，无筛选条件时传 `{}`，返回默认第 `1` 页、每页 `10` 条记录。

| 参数名 | 必填 | 参数类型 | 请求位置 | 说明 |
|---|---|---|---|---|
| current | 否 | Integer | Body | 当前页码，未传、为 `null` 或小于等于 `0` 时使用 `1` |
| size | 否 | Integer | Body | 每页数量，未传、为 `null` 或小于等于 `0` 时使用 `10` |
| riskDetailsId | 否 | Long | Body | 所属风险明细 ID，精确匹配 |
| keyword | 否 | String | Body | 按风险词 `keyword` 字段模糊查询；未传、空字符串或纯空白时不参与筛选 |
| matchType | 否 | Integer | Body | 匹配类型，精确匹配：0-全量匹配，1-包含匹配 |

## 前端对接注意事项

1. 统一使用 `/knowledge/risk/keyword` 路径前缀，各接口路径和请求方式见本文对应章节。
2. 创建、更新、删除接口返回布尔操作结果。请求正常处理时 `code = "0"`，前端还应判断 `data` 是否为 `true`；更新或删除不存在、已删除的记录时，`data` 为 `false`。
3. 查询详情时需要兼容 `data = null`；查询列表和分页时需要兼容空数组。
4. `matchType` 使用 `0` 和 `1`。创建时应主动传入匹配类型，后端不补充默认值，也未声明枚举范围校验。
5. 更新时必须提供有效 `id`。默认仅更新非 `null` 的字段，通过省略字段或传 `null` 无法清空原有值。
6. 删除采用逻辑删除，查询接口不返回已删除记录，也不接受 `deleted` 作为筛选条件或编辑字段。
7. 分页请求体必传；无筛选条件时使用 `{}`。`current`、`size` 小于等于 `0` 时会回退默认值，`keyword` 为空或纯空白时忽略该筛选条件。
8. 风险词对象的时间字段统一按 `yyyy-MM-dd HH:mm:ss` 解析。
